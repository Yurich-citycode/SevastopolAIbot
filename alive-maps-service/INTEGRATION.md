# Как это живёт в боте

Короткая памятка: что уже склеено, где включается и как за десять минут
переехать из бота в мини-апп Telegram.

## Что склеено

```
Telegram → бот (sevastopolaibot.py)
              │ alive_map.py
              ↓ HTTP
        alive-maps-service (localhost:8080)
              ├── GraphHopper — считает быстрый и живой маршруты
              ├── мои точки из «Sevastopol AI База.xlsx»
              └── /api/compare.png — картинка для ответа в чат
```

Бот не тащит ни Pillow, ни проекций: он просит у сервиса готовую картинку и
текст. Если сервис лежит, бот пишет «карта недоступна» и работает дальше —
остальные кнопки не ломаются.

## Что появилось в боте

| Что | Как вызвать |
|---|---|
| Кнопка «🗺 Живая карта» в главном меню | `alive:panel` |
| Команда панели | `/map` |
| Маршрут до места из базы | `/route Фиолент` |
| То же через кнопки | «🚶 Маршрут от меня» → название → 📎 геопозиция |

Ответ выглядит так:

```
🚶 До «Фиолент»

⚡ быстрый: 34 мин · 2.6 км
🌿 живой: 41 мин · 3.3 км (+7 мин)

через: Приморский бульвар (парк), Кофе в Окнах (кафе)
```

и сверху картинка с двумя линиями: пунктир — быстрый, сплошная лаймовая —
живой, светлые точки — мои места из базы.

## Мои точки на карте

Зоны для маршрутов берутся из OpenStreetMap — они одинаковые у всех.
А мои места — нет: это моя база, с моими названиями и моими оценками.

```bash
python tools/export_pois.py          # база → data/pois.geojson
# или, если удобнее через make:
make pois
```

Что попадает в файл: «Где поесть» (кофе, кафе, рестораны, пекарни,
кондитерские) и «Локации» (пляжи, музеи, достопримечательности, прогулки,
смотровые, закаты). Сейчас это ~198 точек.

Дальше сервис сам:
* рисует их на карте (чип «мои места»);
* даёт маршруту надбавку за проход рядом (55–160 м в зависимости от типа);
* называет их в объяснении: «мимо “Кофе в Окнах”».

Обновляется без пересборки: поменял таблицу → `make pois` → сервис
перечитал файл (он следит за датой изменения).

## Настройки в `.env`

```ini
ALIVE_MAP_ON=1
ALIVE_MAP_URL=http://localhost:8080     # куда бот ходит за маршрутами
ALIVE_MAP_PUBLIC=                       # публичный адрес для кнопок и мини-аппа
```

Локальный адрес — это сервис на той же машине (или в той же docker-сети).
Публичный нужен, когда бот живёт на сервере, а карту хочется открыть с телефона.

## Мини-апп за пару минут

Фронтенд к этому уже готов: сам определяет, что открыт внутри Telegram,
растягивается на его вьюпорт, читает точки из ссылки и не ломается в браузере.
Переезд — это только адрес и одна кнопка.

1. **Дай карте адрес с https.** Telegram не открывает http.
   - быстрый вариант без домена: `cloudflared tunnel --url http://localhost:8080`
     (получишь `https://что-то.trycloudflare.com`);
   - постоянный: свой домен + тот же туннель или VPS с Caddy.
2. **Пропиши адрес боту** в `.env`:
   ```ini
   ALIVE_MAP_PUBLIC=https://map.твой-домен.ру
   ```
   и перезапусти бота.
3. **Включи кнопку-меню** в @BotFather:
   `/setmenubutton` → выбери бота → пришли адрес карты.
4. Готово: у бота слева от поля ввода появится кнопка, карта откроется
   мини-аппом.

Проверить, что всё на месте, можно по `https://<адрес>/api/config` — там
видно `own.count` (мои места), `zones.count` и статус GraphHopper.

## Ссылки с точками

Карта понимает параметры в адресе:

```
https://<адрес>/?from=44.605000,33.515000&to=44.612000,33.533000
```

Порядок — как в Telegram: сначала широта, потом долгота. Открылась — сразу
с посчитанными маршрутами. Этими ссылками можно делиться в чатах, а бот
подставляет их в кнопку «🗺 Открыть на карте».

## Что можно добавить дальше

* **Свои тайлы из скана или фото.** Геопривязать картинку в QGIS (3–4
  контрольные точки), нарезать `gdal2tiles.py` в MBTiles и положить рядом с
  `sevastopol.mbtiles`. TileServer отдаст её как отдельный слой.
* **Свои дорожки.** Обвести тропинки парка или набережной в JOSM, сохранить в
  `.osm` и указать его в `graphhopper/config.yml` как `datareader.file` —
  тогда маршрут пойдёт по твоим тропам, а не по OSM.
* **Сезонные зоны.** Ремонт, перекрытия, «зимой тут не пройти» — тот же
  `pois.geojson`, только с полигонами вместо точек.
