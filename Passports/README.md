# CITY CODE PASSPORT — визуальная система

Паспорт закрытого городского круга **City Code, Севастополь**.
Это документ-удостоверение ранга: не бренд-хаб, не финансовый продукт, не коллекционный
токен «про всё». Бумага, тиснение, фото, наборный текст. Никакого интерфейса бота,
прогресс-баров, QR оплат, глитча, лайма и розового.

Два носителя из одной системы:

1. **Физический паспорт-книжка** — один шаблон на весь тираж (`print/`).
   Меняются только данные человека и фото.
2. **NFT-карточка** (`nft/`) — та же лицевая страница в кадре-карточке.
   Уникальность — только номером паспорта и температурой свечения.

Физический паспорт получает только ранг **City Code** — порог **7000 XP**.

Ни на одной стороне, странице, NFT и в подписях не должно встречаться:

- `YurichHub`, `YURICHHUB`, `HUB`
- `ЦФА`, `CFA`, `RWA`, `Crimea RWA`
- `Sevastopol AI`
- курс, глоссарий, оферта, доходность, токенomics, whitelist

Разрешённый текст на макете — только: `CITY CODE`, `SEVASTOPOL`, `PASSPORT`,
`CC-XXXXXX` (номер), `ИМЯ`, `РАНГ`, `СТАТУС`, `ДЕЙСТВИТЕЛЕН`, `ВЫДАН`, `XP`,
`ОТМЕТКИ`, `Ранг за вклад в город`, координаты, шесть строк круга и даты.

## Книжка: постранично

- **Обложка (лицо)** — тёмная ткань/картсток, почти чёрная. Тиснение `CITY CODE`,
  мельче `SEVASTOPOL`. Один сдержанный знак-вотермарк: простая связка ключей /
  кольцо, полупрозрачно, монохром. Ничего государственного.
- **Оборот обложки** — только `CITY CODE` и координаты `44.6167 N · 33.5258 E`.
- **Страница 1 — данные.** Слева фото держателя в простой тонкой рамке (поле
  заменяемое: сейчас фото основателя, дальше — то, что человек пожелает поставить).
  Справа/ниже — наборные поля документа (см. линейку полей). Внизу мелко:
  «Ранг за вклад в город». Никаких юридических брендов.
- **Страница 2 — круг.** Шесть строк без расшифровок:
  `Code · Privileges · Partner Circle · Events · Insights · Member Circle`.
- **Страницы 3–8 — ОТМЕТКИ.** Сетка под штампы достижений; в шаблоне все места
  пустые. Штамп ставится позже поверх: место, событие, узел, год и т.д.
  Никаких «уже полученных» ачивок в макете.

## NFT: правила уникализации

Меняется **только**:

1. номер `CC-XXXXXX`;
2. цвет свечения — обводка рамки фото и тонкая кромка карточки, спокойный rim light,
   одна температура на токен. Не радуга, не неон.

Соответствие «номер → температура» для первой серии (на самих NFT названия цветов
словами не пишутся):

| Окончание номера | Температура свечения |
| ---------------- | -------------------- |
| …92              | холодный белый       |
| …93              | тёплое золото        |
| …94              | морская зелень       |
| …95              | янтарь               |

Композиция от номера не меняется. Лицо не генерируется заново — фото то же поле,
что в книжке (сейчас основатель, далее фото держателя).

**Гравируется в шаблоне навсегда** (не трогаем от выпуска к выпуску):

- `CITY CODE · SEVASTOPOL` (обложка, оборот, страницы, NFT)
- координаты `44.6167 N · 33.5258 E` (оборот обложки)
- сетка страниц и гильошная рамка, вотермарк «связка ключей»
- рамка фото (геометрия, толщина линии)
- названия полей: `CITY-PASSPORT`, `ИМЯ`, `РАНГ`, `СТАТУС`, `ДЕЙСТВИТЕЛЕН`,
  `ВЫДАН`, `XP`
- константы уровня: `XP 7000+`, строка «Ранг за вклад в город»,
  шесть строк круга на стр. 2, заголовок `ОТМЕТКИ`

**Переменные** (заполняются на человека):

- фото держателя
- имя
- номер паспорта `CC-XXXXXX`
- дата выдачи (`ВЫДАН Севастополь · ДД.ММ.ГГГГ`)
- срок `ДЕЙСТВИТЕЛЕН до ДД.ММ.ГГГГ`
- значения `РАНГ` и `СТАТУС` (по реестру рангов; по умолчанию статус `CITY CODE`)
- цвет свечения NFT (по окончанию номера, таблица выше)

**Ставится позже, никогда не печатается в макете:** штампы достижений на стр. 3–8.
