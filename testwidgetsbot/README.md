# Тест-виджеты-бот

Отдельный бот, где вся навигация живёт в одном сообщении: разделы, списки,
карточки мест, маршруты, паспорт. Главный бот отсюда ничего не берёт и не
трогает — это самостоятельная папка со своим файлом и своим токеном.

## Что внутри

| Файл | Что делает |
|---|---|
| `testbotwidgets.py` | сам бот: опрос Telegram, экраны, ответы на нажатия |
| `testbot_widget.html` | шаблон сообщения-виджета (интерфейс, кнопки, стили) |
| `TESTBOT.bat` | Windows: двойной клик, спросит токен и запустит |
| `colab_testwidgets.ipynb` | то же самое без своего компьютера, через Colab |
| `token.txt` | токен тестового бота, создаётся сам, в git не попадает |
| `.passport.json` | прогресс по разделам, создаётся сам, в git не попадает |

Таблица берётся из корня репозитория — `Sevastopol AI База.xlsx`. Если положить
копию рядом с ботом, возьмётся она.

## Три способа запустить

1. **Windows, двойной клик:** `TESTBOT.bat` в этой папке. Спросит токен один
   раз, сохранит рядом в `token.txt` и запустит.
2. **Colab:** залить `colab_testwidgets.ipynb` в
   [colab.research.google.com](https://colab.research.google.com) (Файл →
   Загрузить блокнот) и выполнить ячейки по порядку. Токен спросит полем ввода,
   в блокнот он не пишется.
3. **Вручную из корня репозитория:**

```bat
set TG_TOKEN=123456:AA...
python testwidgetsbot\testbotwidgets.py
python testwidgetsbot\testbotwidgets.py --check            :: размеры всех экранов
python testwidgetsbot\testbotwidgets.py --preview .        :: предпросмотр в браузере
python testwidgetsbot\testbotwidgets.py --beta             :: сразу через бету Telegram
python testwidgetsbot\testbotwidgets.py --test-widget      :: пустят виджет или нет
python testwidgetsbot\testbotwidgets.py --version          :: какая версия кода
```

Токен — от **отдельного** бота: @BotFather → `/newbot`. Токен главного бота не
подойдёт, два бота на одном токене мешают друг другу.

## Что умеет

| Раздел | Что внутри |
|---|---|
| Где поесть | 6 категорий → список → карточка с описанием, адресом, меню |
| Локации | 55 мест с категорией и ориентиром |
| События | лента из таблицы: дата, место, цена |
| Маршруты | 7 маршрутов: длина, сложность, описание |
| Паспорт | XP, звание, полоска до следующего |

## Виджеты сейчас выдают не всем ботам

Telegram ответил на живом боте прямо: `INPUT_MEDIA_WIDGET_NOT_ALLOWED` — и на
обычном адресе, и на бете. HTML при этом в норме: 11 474 байта при лимите
32 768, после сжатия 3 450 при лимите 4 096. То есть отказывает сервер, а не
код: новинку раздают по белому списку, заявку туда не подать.

Как бот ведёт себя дальше:

1. пробует отправить виджет обычным адресом;
2. на отказ пробует `api.telegram.org/beta`;
3. если и там отказали — показывает **те же экраны** обычным сообщением с
   кнопками: разделы, списки, карточки, точки маршрута. Всё листается в одном
   сообщении, новых сообщений не появляется.

Отказ запоминается на 10 минут: первый `/start` тратит две попытки, дальше меню
приходит мгновенно. Раз в 10 минут бот тихо перепроверяет — откроют доступ,
виджет включится сам, без перезапуска и правок.

Проверить в любой момент, не останавливая бота — написать ему в чат:

```
/testwidget
```

Ответ скажет всё: размеры против лимитов, что ответил обычный адрес, что бета,
и покажет меню на кнопках.

## Лимиты, под которые подогнан виджет

| Лимит | Значение | Как есть |
|---|---|---|
| HTML | 32 768 байт | 11 474 |
| после сжатия | 4 096 байт | 3 450 |
| ответ бота на запрос виджета | 1 024 байта | самый большой экран 743 |
| запрос из виджета | 1–64 байта | `l:food:coffee:0` |
| чаты | только личные | в группах не работает |

## Если что-то не так

| Симптом | Что на самом деле |
|---|---|
| `Read timed out` | сеть не дотянулась до Telegram: бот сам повторит трижды, потом скажет. Перезапусти; если повторяется в Colab — запусти на своём компьютере |
| `getMe: Unauthorized` | токен неверный или отозван: @BotFather → `/token` |
| «Это не похоже на токен» | вставили не токен: он выглядит как `8123456789:AAH…` |
| токен попал в переписку или на скриншот | сразу @BotFather → `/revoke`, старый перестанет работать |
| карточка пустая, «Widget unavailable» | бот не в белом списке Telegram: он переключился на кнопки, разделы те же |
| в логах нет версии в первой строке | работает старый код: останови и запусти заново |
