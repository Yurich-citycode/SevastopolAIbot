# Форвардер постов каналов (отдельный сервис)

`events/forwarder.py` — самостоятельный скрипт, **не часть основного бота**.
У него свой второй бот, свой токен и свои настройки. Основной бот при этом
может работать или не работать — это ни на что не влияет.

**Что делает:** следит за каналами из `events/sources.json` и в реальном
времени копирует их посты (текст, фото, видео, альбомы, caption — с
сохранением форматирования) в личный чат владельца, добавляя под каждым
постом ссылку на оригинал.

Зависимостей нет — только стандартная библиотека Python 3.8+. Ничего
устанавливать не нужно (`pip install` не требуется).

---

## Настройка с нуля (5 минут)

### 1. Второй бот
1. В Telegram открыть **@BotFather** → `/newbot`.
2. Имя (например, `Sevastopol Watcher`) и username (например,
   `sevastopol_watcher_bot`).
3. BotFather выдаст токен вида `123456789:AAA...` — **это токен только для
   форвардера**, его не путать с токеном основного бота. В git его не
   коммитим: он живёт в переменной окружения `FORWARDER_BOT_TOKEN`.

### 2. Бот — админ исходных каналов
Для каждого канала, откуда нужно копировать:
1. Канал → **Управление каналом** → **Администраторы** → **Добавить
   администратора**.
2. Найти второго бота по username и добавить (права «Публикация сообщений»
   по умолчанию — достаточно; бот читает посты только если он админ).

> Публичные каналы можно писать в списке как `@username`, частные — числом
> вида `-1001234567890`.

### 3. Целевой чат (личка владельца)
1. Открыть чат со вторым ботом, нажать **Start** (обязательно — иначе бот
   не сможет писать первым).
2. Определить id чата одной командой:
   ```bash
   python events/forwarder.py setup --save
   ```
   Скрипт напечатает `target_chat_id` и сам сохранит его в
   `events/sources.json`.

### 4. Список каналов
В `events/sources.json` заполнить:
```json
{
  "target_chat_id": 6106999216,
  "channels": [
    "@channel_one",
    "@channel_two",
    "-1001234567890"
  ]
}
```

### 5. Токен и запуск
```bash
export FORWARDER_BOT_TOKEN="123456789:AAA..."   # Windows: set FORWARDER_BOT_TOKEN=...
python events/forwarder.py run
```
Либо положить рядом файл `events/.env` со строкой
`FORWARDER_BOT_TOKEN=123456789:AAA...` — скрипт сам его прочитает.

Стоп — `Ctrl+C`. Посты, пришедшие пока скрипт не работал, не теряются:
смещение (`events/forwarder_state.json`) хранится и после перезапуска
докопирует пропущенное. Начать «с чистого листа» (только новые посты):
```bash
python events/forwarder.py run --reset
```

## Как это работает

- Второй бот должен быть **админом канала-источника** — тогда Telegram
  присылает ему новые посты канала (long polling, задержка ~1–3 c).
- Текстовые посты копируются с исходным форматированием (жирный, курсив,
  ссылки), к ним дописывается `🔗 ссылка на оригинал`.
- Фото/видео/документы копируются как есть (`copyMessage`), caption
  сохраняется, ссылка на оригинал идёт отдельной строкой-ответом.
- Альбомы копируются целиком одной группой, одна ссылка на альбом.
- Посты только из каналов из `sources.json` — если бота добавят куда-то ещё,
  чужие посты игнорируются.
- Токен читается из `FORWARDER_BOT_TOKEN` (env) или `events/.env`; в git не
  попадает (`.env` в `.gitignore`).
