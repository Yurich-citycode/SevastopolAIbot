# Виджеты в сообщениях (Bot API 10.4)

Пробная копия бота на HTML-виджетах. Рабочий `sevastopolaibot.py` не тронут:
это отдельный файл, который можно просто не запускать.

## Что это такое

Telegram разрешил ботам вставлять в сообщение небольшой HTML — до 32 КБ, после
сжатия до 4 КБ. Внутри работает JavaScript в песочнице, и у него есть ровно один
выход наружу:

```js
TelegramWidget.request("pick:2").then((answer) => {
  // answer.result — до 1024 байт, которые прислал бот
});
```

Бот получает это как `widget_query`, отвечает `answerWidgetQuery` — и виджет
перерисовывается **в том же сообщении**. Никаких новых сообщений, никакой
страницы, никакого мини-аппа. Состояние живёт у бота, поэтому его можно менять
и снаружи через `editMessageWidgetData`.

## Что здесь есть

| Файл | Что делает |
|---|---|
| `alive_widget.html` | шаблон карточки с тремя маршрутами; данные подставляются вместо `__DATA__` |
| `demo_bot.py` | проба: опрос Telegram, `/map <место>`, отправка виджета, ответы на нажатия |
| `preview.html` | готовый предпросмотр с демо-данными — открывается в любом браузере |

## Посмотреть, как выглядит

Открой `preview.html` двойным щелчком. Внутри заглушка: `TelegramWidget.request`
отвечает сама себе, поэтому строки переключаются, как в Telegram.

## Запустить в Telegram

```bat
set TG_TOKEN=123456:AA...          :: токен тестового бота
python widgets\demo_bot.py
```

Дальше в личном чате: `/map музей` → скинуть геопозицию → придёт карточка.

```bat
python widgets\demo_bot.py --check  :: проверить, что виджет влезает в лимиты
```

## Почему отдельный бот и отдельный файл

* aiogram Bot API 10.4 пока не поддерживает (issue #2006), поэтому здесь прямые
  вызовы `api.telegram.org` через `requests`. Рабочего бота это не касается.
* виджеты сейчас работают **только в личных чатах** и не пересылаются —
  для пробы нужен свой тестовый бот, чтобы не мешать основному.

## Ограничения, которые придётся учитывать

| Лимит | Значение | Как обходим |
|---|---|---|
| HTML | 32 КБ, после zlib — 4 КБ | шаблон весит 2,7 КБ после сжатия |
| запрос из виджета | 1–64 байта | шлём `pick:0`, `pick:1`, `pick:2` |
| ответ бота | 1024 байта | отдаём сжатый JSON трёх маршрутов (258 байт) |
| время ответа | 15 секунд | сервис карты локальный, отвечает за секунды |
| частота | 5 запросов за 5 секунд с человека | больше и не нужно: один тап — один запрос |
| чаты | только личные | в группах пока не работает |

## Что из этого можно сделать в основном боте

Карточка маршрута — очевидный кандидат: сейчас бот присылает картинку и текст,
а человек не может переключиться между «быстрым», «живым» и «самым живым» без
нового сообщения. С виджетом это один тап в том же сообщении.

Ограничение по 4 КБ значит, что карту внутри сообщения не нарисуешь — только
цифры, полоски и кнопки. Всё, что нужно от карты (линии, зоны), остаётся
картинкой или мини-аппом; виджет — это панель управления к ней.

# Тест-бот виджетов

`testbotwidgets.py` — дубль бота, где **весь** интерфейс в виджете: еда, локации,
события, маршруты, паспорт. Главный бот не тронут.

**Три способа запустить**

1. **Windows, двойной клик:** `TESTBOT.bat` в корне репозитория. Спросит токен
   один раз, сохранит в `widgets/token.txt` (в git не попадает) и запустит.
2. **Colab:** `widgets/colab_testbot.ipynb` — залить в
   [colab.research.google.com](https://colab.research.google.com) (Файл → Загрузить блокнот)
   и выполнить ячейки по порядку. Токен спросит, в блокнот не пишется.
3. **Вручную:**

```bat
set TG_TOKEN=123456:AA...
python testbotwidgets.py
python testbotwidgets.py --check            :: размеры всех экранов
python testbotwidgets.py --preview widgets  :: превью для браузера
```

**Дальше в Telegram:** найти своего тестового бота по юзернейму → Start.
Карточка должна прийти сразу; если пришёл текст — обнови Telegram.

### Если не подключается

| Симптом | Что на самом деле |
|---|---|
| `Read timed out` | сеть не дотянулась до Telegram: бот сам повторит трижды, потом скажет. Перезапусти ячейку/окно; если повторяется в Colab — запусти локально |
| `getMe: Unauthorized` | токен неверный или отозван: @BotFather → `/token` |
| «Это не похоже на токен» | вставили не токен: в коде должно быть `getpass("…")` без самого токена, а токен — только в поле ввода |
| токен попал в переписку/скриншот | сразу `@BotFather` → `/revoke` → новый токен, старый перестанет работать |

Что умеет:

| Раздел | Что внутри |
|---|---|
| Где поесть | 6 категорий → список → карточка с описанием, адресом, меню |
| Локации | 55 мест с категорией и ориентиром |
| События | лента из таблицы: дата, место, цена |
| Маршруты | 7 маршрутов: длина, сложность, описание |
| Паспорт | XP, звание, полоска до следующего |
| Живая карта | три варианта маршрута из локального сервиса |

Технически: один HTML на все экраны, при загрузке виджет спрашивает `boot`,
каждое нажатие — запрос к боту и ответ до 1024 байт. Все экраны влезают:
самый большой 743 байта, HTML 11,5 КБ (3,4 КБ после сжатия при лимите 4 КБ).
